# Nebula Vision — AI Vision Inspection & Measurement

Our project is a smartphone-based AI vision inspection system for mechanical components.

Normally, industries use expensive cameras and special inspection machines to check whether a component is made correctly. Our idea is to do the basic inspection using just a smartphone camera.

The user shows a component to the camera. The system first identifies what the component is, then uses a known reference such as a ruler to understand the scale.

After calibration, it can estimate important dimensions like length, width, diameter and other measurements. It also checks the component for visible problems such as damaged edges, missing holes, deformation or incorrect geometry.

If the component is a fastener like a bolt, the system can also compare it with a standards database and give an approximate identification such as M10 × 1.5 × 50.

Finally, all the information is combined and the system gives an engineering result such as PASS, FAIL or REVIEW, along with a confidence/trust value. It can also generate a PDF inspection report.

So, in simple terms, we are trying to turn a normal smartphone into a basic AI-assisted engineering inspection tool.
